# NH / JL 航空燃油附加费监控

只监控以下两家日本航司的“中国大陆-日本”航线燃油附加费：

- `NH`：ANA（全日空）
- `JL`：JAL（日本航空）

## 检查节奏

每一轮在偶数月开始：

1. 偶数月 20 日检查；
2. 若某家航司没有发布，25 日只重查未发布的航司；
3. 若仍未发布，下一奇数月 2 日再只重查未发布的航司。

例如 10 月 20 日、10 月 25 日、11 月 2 日属于同一轮；下一轮是 12 月 20 日、12 月 25 日、次年 1 月 2 日。

如果 20 日已查到 NH 和 JL 两家的下一期记录，25 日和次月 2 日会自动跳过。如果只查到一家，后续日期只检查另一家。也可以从 Actions 页面手动运行，手动运行不受日期限制。

## 历史保留方式

- `data/NH.csv` 只保存 ANA（NH）的追加式历史记录。
- `data/JL.csv` 只保存 JAL（JL）的追加式历史记录。
- 两个 CSV 互不混合，只保留“中国大陆-日本”航线；分别记录燃油单程价格与燃油往返价格（往返为单程的 2 倍）。新一期或同一期金额发生变化时追加新行，不删除旧记录。
- `data/state.json` 记录每轮 NH、JL 是否已经发布，用于避免 25 日和次月 2 日重复访问。
- `reports/latest.md` 展示两家航司最近一期的燃油单程价格和燃油往返价格。
- 发现新记录时，工作流会提交数据并创建一个 GitHub Issue 通知。

监控以航司官方页面的“东亚（韩国除外）”价格档位为数据源，该档位适用于中国大陆-日本航线。若官方站点拒绝自动访问，脚本会尝试官方页面的只读文本镜像；两种方式都失败时，该航司保持“未完成”，在本轮下一候选日继续重试。

## 本地运行

```bash
python -m pip install -r requirements.txt
FORCE_CHECK=1 python -m src.monitor
```

测试指定日期可使用：

```bash
MONITOR_DATE=2026-10-20 python -m src.monitor
```
